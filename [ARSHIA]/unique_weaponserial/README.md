# unique_weaponserial

سیستم سریال کامل برای اسلحه‌ها: هر اسلحه‌ای که هرکسی می‌گیره (قانونی یا غیرقانونی)
یه سریال منحصربه‌فرد داره، می‌تونی چند نسخه از یه نوع اسلحه رو هم‌زمان داشته باشی،
دراپ کردن و برداشتن سریال رو حفظ می‌کنه، و پلیس می‌تونه سریال رو چک کنه.

## محدودیت مهم موتور بازی (نه یه باگ)

TAB (چرخ اسلحه) خودِ GTA فقط می‌تونه **یک** نمونه از هر نوع اسلحه رو هم‌زمان نشون
بده -- این محدودیت خودِ بازیه، هیچ اسکریپتی نمی‌تونه دورش بزنه. برای همین:

- همیشه فقط **یکی** از هر نوع اسلحه «فعال» (تو دستت/تو TAB) هست.
- بقیه‌ی نسخه‌ها (اگه چندتا از یه نوع داشته باشی) به‌صورت آیتم جدا تو اینونتوریت
  می‌مونن ("holstered"/spare).
- با "use" کردن یکی از این آیتم‌ها تو اینونتوری، همونی که تو دستته میره تو
  اینونتوری (به‌عنوان آیتم) و اون یکی میاد تو دستت/TAB -- یعنی خودت انتخاب می‌کنی
  کدوم سریال الان فعاله.

## چیکار می‌کنه

- **هر خرید/دریافت اسلحه = یه سریال جدید.** این از طریق `xPlayer.addWeapon`
  اتفاق می‌افته -- یعنی **هر مغازه‌ی اسلحه یا دستور ادمینی که از این تابع استاندارد
  ESX استفاده کنه**، خودکار سریال می‌گیره، بدون هیچ تغییری تو خودِ اون مغازه‌ها.
- **دراپ‌کردن اسلحه‌ی تو دست:** دستور `/dropweapon` (یا کلید `X`، قابل تغییر از
  تنظیمات کیبورد بازی). اسلحه رو تبدیل به آیتم می‌کنه و می‌ندازتش زمین -- از سیستم
  دراپ/پیکاپ خودِ `esx_inventoryhud` استفاده می‌کنه (چون از قبل کار می‌کنه)، پس
  سریال دقیقاً حفظ می‌شه وقتی یکی دیگه برش می‌داره.
- **چک سریال پلیس:** دستور `/checkserial <کد>` (فقط برای جاب‌های `police`,
  `sheriff`, `government` -- اگه اسم جاب‌های پلیس سرورت فرق داره، تو
  `server/main.lua` جدول `PoliceJobs` رو عوض کن). نوع اسلحه، وضعیت فعلی (equipped/
  carried/unowned)، اسم دارنده‌ی فعلی، و اینکه اصلاً به کی ثبت شده رو نشون می‌ده.

## یه محدودیت که باید بدونی

سریال فقط برای اسلحه‌هایی ساخته می‌شه که از طریق `xPlayer.addWeapon` (تابع
استاندارد ESX) داده شده باشن. اگه یه مغازه‌ی خاص یا اسکریپت دیگه‌ای رو سرورت
مستقیم با نیتیوهای GTA (`GiveWeaponToPed`) اسلحه می‌ده و از `xPlayer.addWeapon`
رد نمی‌شه، اون اسلحه سریال نمی‌گیره. اگه به همچین اسکریپتی برخوردی، بگو تا جدا
هوکش کنم.

## نصب

1. پوشه‌ی `unique_weaponserial` رو بذار داخل `[ARSHIA]` (کنار بقیه).
2. چون `ensure [ARSHIA]` خودکار همه‌چیز داخلش رو بالا میاره، نیازی به تغییر
   `server.cfg` نیست.
3. مطمئن شو `essentialmode` و `esx_inventoryhud` هر دو قبل از این بالا میان
   (هستن، هیچی بهشون دست نزدم).
4. سرور رو ری‌استارت کن (یا `restart unique_weaponserial` بعد از یه بار
   `restart essentialmode` اگه essentialmode رو تازه پچ کردی).

## نکته‌ی فنی برای بعداً (اگه خواستی گسترشش بدیم)

- الان `/checkserial` یه دستور مستقله. اگه یه سیستم MDT واقعی رو سرورت داری (یا
  می‌سازی)، تابع `GetWeaponSerial(serial)` رو export/صدا بزن -- همه‌چیز
  (نوع اسلحه، وضعیت، دارنده‌ی فعلی، ثبت‌شده به کی) رو برمی‌گردونه، بدون نیاز به
  دستور جدا.
- کامپوننت‌های اسلحه (خشاب بزرگ، دوربین، ...) هم با هر سریال ذخیره و موقع تعویض
  دوباره نصب می‌شن.
