# AntiCheat

یه ماژول **کاملاً مستقل و جدا** از UNIQUE_AC که با تشخیص ناهنجاری آماری
(anomaly detection) — نه دست‌زدن به فایل‌های اصلی UNIQUE_AC که خیلی بزرگ و
حساسن — سعی می‌کنه رفتار مشکوک رو با false-positive کمتر تشخیص بده. هر وقت
خواستی می‌تونی حذفش کنی بدون اینکه چیزی از UNIQUE_AC بشکنه.

## صادقانه درباره‌ی "ML"

منظور از ML اینجا آمار آنلاین/بدون‌نظارت (رولینگ میانگین + انحراف معیار به
روش Welford + امتیاز z-score) و چند تا قانون آستانه‌ای هوشمند هست — دقیقاً
همون رویکردی که خود UNIQUE_AC هم توی `AimbotWatch` و `BehavioralClustering`
استفاده کرده (با همون کامنت صادقانه‌ی «simplified heuristic, not real ML»).
هیچ شبکه‌ی عصبی/آموزش دیتایی در کار نیست — Lua روی سرور بازی واقع‌بینانه
نمی‌تونه ML سنگین اجرا کنه، و ادعای خلافش فقط تیونینگ رو سخت‌تر می‌کرد.

## نصب

1. پوشه‌ی `AntiCheat` رو بذار توی `resources`
2. (اختیاری، برای تاریخچه‌ی پرسیستنت) کوئری `sql/install.sql` رو روی دیتابیس اجرا کن و `Config.Persistence.Enable = true` کن
3. توی `config.lua`، `Config.Actions.DiscordWebhook` رو ست کن
4. توی `server.cfg`:

```
ensure AntiCheat
```

## ۱۲ دسته‌ی تشخیص

هرکدوم مستقل قابل روشن/خاموش‌کردنه (`Config.<X>.Enable`)، همه به Trust Score
مشترک وصلن (نه ban فوری — فقط KICK نرم + گزارش Discord؛ بن واقعی همیشه
تصمیم آدمینه):

| دسته | چی می‌گیره | چطور |
|---|---|---|
| **Speed** | اسپیدهک پیاده/سواره | baseline شخصی هر بازیکن (Welford) + z-score + سقف مطلق |
| **Teleport** | جهش موقعیت | فاصله‌ی خط‌مستقیم بین دو سمپل تقسیم‌بر زمان، مستقل از چیزی که بازی گزارش می‌ده |
| **Noclip** | رد شدن از دیوار/معلق‌موندن | ۳ سیگنال مستقل (کالیژن غیرفعال، هاور بی‌دلیل، ray-test) — حداقل ۲تا لازمه |
| **Super Jump** | پرش غیرطبیعی | سرعت عمودی پرش بالاتر از حد طبیعی، الگوی تکرارشونده |
| **God Mode** | آسیب‌ناپذیری | مقایسه‌ی رویداد "باید ضربه می‌خورد" با افت واقعی HP |
| **Instant Refill** | پرشدن ناگهانی HP/زره | جهش بزرگ بدون توضیح، سیگنال نرم (بیشتر برای correlation) |
| **Infinite Ammo** | فشنگ بی‌نهایت | بعد شلیک تایید‌شده، فشنگ کم نشه |
| **Fire Rate** | تیراندازی سریع‌تر از حد اسلحه | فاصله‌ی بین شلیک‌ها کمتر از cycle time واقعی اسلحه |
| **Weapon Blacklist** | سلاح نظامی روی غیرنظامی | RPG/Minigun/Railgun و مشابه |
| **Vehicle Handling** | شتاب غیرممکن وسیله | تغییر سرعت در واحد زمان بالاتر از حد فیزیکی |
| **Invisibility** | نامرئی‌شدن غیرمجاز | `IsEntityVisible` false به‌صورت پایدار |
| **Resource Whitelist** | ریسورس ناشناس روی کلاینت | ⚠️ محدودیت مهم: پایین رو بخون |

### ⚠️ محدودیت واقعی Resource Whitelist

`GetNumResources`/`GetResourceByFindIndex` فقط ریسورس‌هایی رو می‌بینه که از
سیستم رسمی FiveM لود شدن. **مدمنیوهای معروف (Menyoo، Stand، Redline و…) اصلاً
به‌شکل ریسورس نیستن** و از این چک عبور می‌کنن. این فقط یه لایه‌ی رایگان و
کم‌ریسک اضافه‌ست (مثلاً یه دیباگ‌ریسورس فراموش‌شده)، نه جایگزین چک‌های واقعی
بالا.

## Trust Score

- امتیاز شروع: ۱۰۰، هر پرچم بر اساس شدتش کم می‌کنه
- به‌آرومی هر دقیقه ترمیم می‌شه (`RecoverPerMinute`) تا یه پرچم قدیمی همیشه دنبال بازیکن قانونی نمونه
- `WebhookAtScore`: گزارش Discord
- `KickAtScore`: کیک نرم (نه بن)
- **Correlation**: اگه ۲+ بازیکن مختلف یه پرچم مشترک رو تو یه بازه‌ی کوتاه بزنن (نشونه‌ی ابزار لیک‌شده)، اولویت گزارش بالا می‌ره

## Exports برای پنل ادمین

```lua
exports['AntiCheat']:GetTrustScore(playerId)   -- عدد ۰ تا ۱۰۰
exports['AntiCheat']:GetTrustHistory(playerId) -- آرایه‌ی کامل پرچم‌ها
```

## تنظیم فاین‌تیون

همه‌ی آستانه‌ها (`ZScoreThreshold`, `RequireSignals`, `RequiredOccurrences`,
`ScorePenalty` هرکدوم) توی `config.lua` هستن، هرکدوم با کامنت توضیح داده شده.
اگه بازیکن‌های قانونی گیر افتادن، اول این‌ها رو شل‌تر کن قبل از خاموش‌کردن
کل چک.
