# AntiCheat

یه ماژول **کاملاً مستقل و جدا** از UNIQUE_AC که با تشخیص ناهنجاری آماری (anomaly
detection) سعی می‌کنه اسپیدهک، نوکلیپ و گاد‌مود رو بهتر و با false-positive
کمتر تشخیص بده. عمداً به فایل‌های اصلی UNIQUE_AC (که خیلی بزرگ و حساسن)
دست نمی‌زنه — می‌تونی هر وقت خواستی حذفش کنی بدون اینکه چیزی از UNIQUE_AC
بشکنه.

## صادقانه درباره‌ی "ML"

منظور از ML اینجا آمار آنلاین/بدون‌نظارت (رولینگ میانگین + انحراف معیار به
روش Welford + امتیاز z-score) هست — دقیقاً همون رویکردی که خود UNIQUE_AC هم
توی `AimbotWatch` و `BehavioralClustering` استفاده کرده (با همون کامنت
صادقانه‌ی «simplified heuristic, not real ML»). نتیجه‌ی عملیش خوبه: هر بازیکن
baseline شخصی خودش رو داره (سرعت دو نرمالش، سرعت ماشینش) به‌جای یه عدد ثابت
برای همه، پس هم چیت‌های ظریف‌تر رو می‌گیره هم روی بازیکن‌های قانونی (با پرک
سرعت یا ماشین سریع) کمتر اشتباه می‌زنه.

## نصب

1. پوشه‌ی `AntiCheat` رو بذار توی `resources`
2. (اختیاری، برای تاریخچه‌ی پرسیستنت) کوئری `sql/install.sql` رو روی دیتابیس اجرا کن و `Config.Persistence.Enable = true` کن
3. توی `config.lua`، `Config.Actions.DiscordWebhook` رو ست کن
4. توی `server.cfg`، بعد از `oxmysql` و همون‌جایی که `UNIQUE_AC` رو `ensure` می‌کنی:

```
ensure AntiCheat
```

## چیکار می‌کنه

- **Speed**: هر بازیکن baseline سرعت شخصی خودش رو (پیاده/سواره) یاد می‌گیره؛ فقط وقتی هم از baseline خودش به‌شدت خارج شد هم از سقف مطلق (14 m/s پیاده، 130 m/s سواره) رد شد پرچم می‌خوره.
- **Noclip**: ۳ سیگنال مستقل (غیرفعال بودن کالیژن، معلق ماندن بی‌دلیل تو هوا، رد شدن از داخل جسم جامد با ray-test) — حداقل ۲ تاش باید همزمان true باشن.
- **Godmode**: مقایسه‌ی «باید ضربه می‌خورد» (رویداد آسیب) با افت واقعی HP؛ فقط الگوی تکرارشونده (نه یه فریم تکی) پرچم می‌خوره.
- همه‌چی می‌ره روی یه **Trust Score** به‌ازای هر بازیکن (نه ban فوری). فقط KICK نرم و گزارش Discord به این امتیاز وصله — بن واقعی همیشه تصمیم آدمینه، دقیقاً مثل فلسفه‌ی خود UNIQUE_AC.
- اگه ۲+ بازیکن مختلف تو یه بازه‌ی کوتاه یه پرچم مشترک بزنن (نشونه‌ی ابزار مشترک/لیک‌شده)، اولویت گزارش بالا میره.

## تنظیم فاین‌تیون

همه‌ی آستانه‌ها (`ZScoreThreshold`, `RequireSignals`, `RequiredNoDamageHits`,
`ScorePenalty` هرکدوم) توی `config.lua` هستن. اگه بازیکن‌های قانونی گیر
افتادن، اول این‌ها رو شل‌تر کن قبل از خاموش‌کردن کل چک.
