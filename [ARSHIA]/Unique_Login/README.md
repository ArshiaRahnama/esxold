# Unique_Login

سیستم لاگین با یوزرنیم/پسورد + تایید پیامکی، برای بازیکن‌هایی که Steam
ندارن (خیلی رایج بین بازیکن‌های ایرانی که از FiveM standalone وصل می‌شن).
موقع `playerConnecting` جای کارت Steam، یه فرم لاگین/ثبت‌نام نشون می‌ده.

## ⚠️ نکته‌ی مهم درباره‌ی «دیگه به Steam نیاز نیست»

این سیستم درست کار می‌کنه، ولی یه نکته‌ی فنی هست که باید بدونی: این
اسکریپت نمی‌تونه identifier واقعی FiveM (مثل `steam:` یا `license:`) رو
جعل کنه — اون‌ها توسط خود پلتفرم تعیین می‌شن، نه با کد Lua. کاری که این
اسکریپت واقعاً می‌کنه اینه: یه "لایسنس اختصاصی" خودش می‌سازه
(`generateUniqueLicense`) و برای بقیه‌ی ریسورس‌هات از طریق
`exports['Unique_Login']:getidentifier(src)` در دسترس می‌ذاره.

**این یعنی**: اگه `essentialmode`/ESX یا `UNIQUE_AC` جای دیگه‌ای از
`GetPlayerIdentifiers()` واقعی (license: خودِ FiveM/Rockstar، نه اون
اختصاصی) برای شناسایی کاراکتر/بن استفاده می‌کنن، این دو تا سیستم
identifier جدا از هم می‌مونن. خبر خوب: `license:` واقعیِ FiveM (که از
Rockstar/لانچر میاد) به Steam نیازی نداره و برای بازیکن‌های
standalone-client هم وجود داره — پس اگه essentialmode با همون
`license:` واقعی کار می‌کنه (که تقریباً همیشه همینه)، مشکلی نیست. فقط
مطمئن شو جایی که به‌خاطر نبود Steam خاص کاراکتر گیر نمی‌کنه رو یه تست
واقعی با یه اکانت بدون استیم انجام بدی.

## ۳ باگ/مشکل که فیکس کردم

1. **🔴 باگ بحرانی — بازیکن تا ابد گیر می‌کرد**: `deferrals.done()` توی
   `formPassed` کامنت شده بود. یعنی بعد از لاگین موفق، بازیکن رو صفحه‌ی
   «در حال ورود با اکانت...» برای همیشه می‌موند و هیچ‌وقت وارد سرور
   نمی‌شد (چون هیچ‌جا `TriggerEvent('playerConnecting2', ...)` رو
   handle نمی‌کرد که `done()` رو صدا بزنه). فیکس شد.
2. **🔴 امنیتی — پسورد Plaintext**: پسورد قبلاً مستقیم توی دیتابیس ذخیره
   و مقایسه می‌شد. الان با `SHA2(password, 256)` داخل خودِ کوئری SQL
   هش می‌شه (نه پسورد خام هیچ‌وقت ذخیره می‌شه، نه توی لاگ کوئری می‌افته).
3. **🟡 نصبی — وابستگی اشتباه**: فایل اصلی به `mysql-async` وابسته بود
   ولی `server.cfg` شما فقط `oxmysql` رو ensure کرده — یعنی اصلاً استارت
   نمی‌خورد. به `@oxmysql/lib/MySQL.lua` عوض شد (همون API رو داره، هیچ
   کوئری‌ای عوض نشد).
4. **کلید API پیامک** از توی کد به `config.lua` منتقل شد — اون فایل رو
   از گیت/اشتراک‌گذاری دور نگه دار، چون کلید واقعی داخلشه.

## نصب

1. کوئری `sql/install.sql` رو اجرا کن
2. پوشه رو بذار توی `resources`
3. توی `server.cfg`، **قبل از essentialmode** (چون باید موقع اتصال کار کنه):
```
ensure oxmysql
ensure Unique_Login
```
