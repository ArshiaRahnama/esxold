# Unique_Login

سیستم لاگین با یوزرنیم/پسورد + تایید پیامکی، برای بازیکن‌هایی که Steam
ندارن (خیلی رایج بین بازیکن‌های ایرانی که به‌خاطر اینترنت ملی نمی‌تونن
Steam رو بالا بیارن). موقع `playerConnecting`، **همه** — چه Steam داشته
باشن چه نه — از یه فرم لاگین/ثبت‌نام واحد رد می‌شن.

## ✅ درباره‌ی «دیگه به Steam نیاز نیست»

این دیگه فقط "کار می‌کنه" نیست — از این به بعد Steam کلاً حذف شده و یه
مسیر واحد برای همه هست. essentialmode شخصیت‌ها رو با `license:` **واقعی**
خودِ FiveM شناسایی می‌کنه (`[BASE]/essentialmode/server/player/login.lua`)
— نه با چیزی که این ریسورس می‌سازه — پس این تغییر هیچ خطری برای
کاراکترهای فعلی نداره، چه بازیکن قبلاً با Steam وارد شده باشه چه نه.

## نصب

1. `sql/install.sql` رو اجرا کن (جدول‌های `login_users`,
   `login_reset_throttle`, `login_audit` و ستون `device_license`)
2. پوشه رو بذار توی `resources`
3. توی `server.cfg`، **قبل از essentialmode**:
```
ensure oxmysql
ensure Unique_Login
```
4. (اختیاری) `web/` رو طبق `web/README.md` روی یه هاست PHP جدا دیپلوی کن
   برای پنل بازیابی رمز از بیرون بازی.

## گسترش‌هایی که اضافه شد

1. **حذف کامل شرط Steam**: همه از یه پنل واحد رد می‌شن؛ چون essentialmode
   با `license:` واقعی کار می‌کنه، شخصیت هیچ بازیکنی گم نمی‌شه.
2. **ورود خودکار (Auto-login)**: بعد از اولین لاگین/ثبت‌نام موفق،
   `license:` واقعی دستگاه توی ستون `device_license` ذخیره می‌شه. دفعه‌ی
   بعد از همون دستگاه، پنل اصلاً نشون داده نمی‌شه.
3. **جلوگیری از دور زدن بن**: قبل از نمایش پنل، `license:` واقعی با جدول
   `uniqueac_banlist` (سیستم UNIQUE_AC) چک می‌شه — بن‌شده حتی فرم
   ثبت‌نام رو هم نمی‌بینه، پس با شماره‌ی جدید هم نمی‌تونه برگرده.
4. **محدودیت ارسال پیامک (Rate Limit)**: هر شماره حداکثر ۳، هر IP
   حداکثر ۵ بار در ساعت (`Config.SmsRateLimit` در `config.lua`).
5. **قفل موقت بعد از تلاش ناموفق**: بعد از ۵ پسورد اشتباه پشت‌سرهم روی
   یه یوزرنیم، ۱۵ دقیقه قفل می‌شه (`Config.LoginLockout`).
6. **پنل وب بازیابی رمز** (`web/`): صفحه‌ی PHP مستقل، مستقیم به
   دیتابیس بازی وصل میشه. جزئیات نصب توی `web/README.md`.
7. **Audit Log**: هر تلاش ورود (موفق/ناموفق)، ثبت‌نام، و تغییر رمز توی
   جدول `login_audit` ثبت می‌شه (یوزرنیم، license، device_license، IP،
   نوع اکشن) — برای بعداً که خواستی توی پنل ادمین «فعالیت‌های اخیر» یه
   اکانت رو نشون بدی یا الگوی مشکوک (مثلاً خیلی تلاش ناموفق از IPهای
   مختلف) رو پیدا کنی.
8. **اعلان Discord برای رویدادهای امنیتی**: وقتی یه اکانت که قبلاً یه
   دستگاه شناخته‌شده داشته، از یه دستگاه **متفاوت** وارد بشه، یا وقتی
   رمزش از پنل وب عوض بشه، یه امبد به `Config.DiscordWebhook.SecurityAlerts`
   فرستاده می‌شه (پیش‌فرض خالیه، خودت باید وبهوکشو بسازی و پر کنی).
   ورود دستگاه جدید هیچ‌وقت جلوی بازیکن رو نمی‌گیره — فقط اطلاع‌رسانیه؛
   خودِ بازیکن باید از پنل بازیابی اقدام کنه اگه خودش نبوده.
9. **کیک خودکار سشن فعال بعد از ریست رمز از وب**: اگه همون لحظه یه نفر
   با اون اکانت آنلاینه (مثلاً هکر) و صاحب واقعی رمز رو از پنل وب عوض
   کنه، سشن فعلی بلافاصله Drop می‌شه — دیگه لازم نیست منتظر بمونه تا
   خودش دیس‌کانکت بشه.
10. **مسیر مستقیم ثبت‌نام از توی فرم ورود**: قبلاً اگه بازیکنی که اصلاً
    اکانت نداشت، اول دکمه‌ی «ورود» (به‌جای «ثبت‌نام») رو می‌زد، توی فرم
    لاگین گیر می‌کرد — فقط «فراموشی رمز» و «بازگشت» داشت، هیچ راه مستقیمی
    به ثبت‌نام نبود. الان:
    - یه دکمه‌ی «📝 حساب ندارم، می‌خواهم ثبت‌نام کنم» مستقیم توی فرم ورود اضافه شد
    - اگه یوزرنیم/شماره‌ای که وارد کرده اصلاً توی دیتابیس نباشه، به‌جای
      پیام مبهم «رمز اشتباه است»، پیام واضح «حسابی با این مشخصات پیدا
      نشد» نشون داده می‌شه و مستقیم می‌بردش به مرحله‌ی اول ثبت‌نام

## باگ‌ها/مشکلاتی که فیکس کردم

1. **🔴 باگ بحرانی — بازیکن تا ابد گیر می‌کرد**: `deferrals.done()` توی
   `formPassed` کامنت شده بود. یعنی بعد از لاگین موفق، بازیکن رو صفحه‌ی
   «در حال ورود با اکانت...» برای همیشه می‌موند و هیچ‌وقت وارد سرور
   نمی‌شد (چون هیچ‌جا `TriggerEvent('playerConnecting2', ...)` رو
   handle نمی‌کرد که `done()` رو صدا بزنه). فیکس شد.
2. **🔴 باگ بحرانی — کیک اشتباهِ بازیکن‌های پشت IP مشترک**: تشخیص «ورود
   دوباره با همون اکانت» قبلاً بر پایه‌ی IP بود (یه Map با یه اسلات به‌ازای
   هر IP). اگه دو نفر با **دو اکانت کاملاً متفاوت** از یه IP عمومی مشترک
   (خیلی رایج بین بازیکن‌های ایرانی: VPN/فیلترشکن، اینترنت همراه با
   CGNAT، وای‌فای مشترک خونه/خوابگاه/کافه‌نت) نزدیک به هم وصل می‌شدن،
   اسلات مربوط به اون IP overwrite می‌شد و هر دو نفر با پیام «اکانتت جای
   دیگه واردشده، پسوردتو عوض کن» کیک می‌شدن — کاملاً بی‌گناه. الان تشخیص
   مستقیم روی `license` هر اکانت انجام می‌شه (`activeLicenseSessions`)،
   نه از پشت IP، پس این تداخل امکان‌پذیر نیست، ولی تشخیص واقعیِ «همون
   اکانت از دو جا» هنوز درست کار می‌کنه.
3. **🔴 امنیتی — پسورد Plaintext**: پسورد قبلاً مستقیم توی دیتابیس ذخیره
   و مقایسه می‌شد. الان با `SHA2(password, 256)` داخل خودِ کوئری SQL
   هش می‌شه (نه پسورد خام هیچ‌وقت ذخیره می‌شه، نه توی لاگ کوئری می‌افته).
4. **🟡 امنیتی — کد OTP توی کنسول سرور لاگ می‌شد**: `print(phone .. " : " .. code)`
   کد تأیید رو خام توی کنسول/لاگ سرور می‌نوشت؛ هرکی به لاگ‌ها دسترسی
   داشت (یا لاگ لو می‌رفت) کد رو می‌دید. حذف شد.
5. **🟡 امنیتی — کد میانبر مرده برای OTP**: یه مسیر (`back` توی مرحله‌ی
   نهایی ثبت‌نام) بود که کد تأیید رو به `"123456"` هارد‌کد می‌کرد — یعنی
   عملاً یه کد میانبر همیشگی برای رد کردن تأیید شماره. دکمه‌ش کامنت شده
   بود پس فعلاً قابل اجرا نبود، ولی حذفش کردم چون یه اسلحه‌ی پر توی کد بود.
6. **🟡 عدم‌تطابق زمان اعتبار OTP**: توی UI نوشته شده «کد تا ۲ دقیقه
   معتبره» ولی واقعاً ۱ ساعت (`1*60*60*1000`) توی حافظه می‌موند — یعنی
   پنجره‌ی حدس‌زدن کد ۶ رقمی خیلی بزرگ‌تر از چیزی بود که به کاربر گفته
   می‌شد. زمان واقعی رو به همون ۲ دقیقه‌ای که UI میگه محدود کردم.
7. **🟡 نصبی — وابستگی اشتباه**: فایل اصلی به `mysql-async` وابسته بود
   ولی `server.cfg` شما فقط `oxmysql` رو ensure کرده — یعنی اصلاً استارت
   نمی‌خورد. به `@oxmysql/lib/MySQL.lua` عوض شد (همون API رو داره، هیچ
   کوئری‌ای عوض نشد).
8. **کلید API پیامک** از توی کد به `config.lua` منتقل شد — اون فایل رو
   از گیت/اشتراک‌گذاری دور نگه دار، چون کلید واقعی داخلشه. **⚠️ این کلید
   الان توی همون ریپازیتوری گیت‌هابی که این پروژه توشه، به‌صورت واقعی و
   فعال commit شده — اگه ریپو پابلیکه، همین الان از پنل sms.ir ریوکش کن.**

## نصب

1. کوئری `sql/install.sql` رو اجرا کن
2. پوشه رو بذار توی `resources`
3. توی `server.cfg`، **قبل از essentialmode** (چون باید موقع اتصال کار کنه):
```
ensure oxmysql
ensure Unique_Login
```
